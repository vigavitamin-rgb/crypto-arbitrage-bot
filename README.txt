ПРОВЕРКА API ВОСЬМИ БИРЖ (только публичные данные, без сделок)
Windows PowerShell:
py -m pip install -r requirements.txt
py scanner.py

Linux:
python3 -m pip install -r requirements.txt
python3 scanner.py

Результаты: connectivity.csv.
elapsed_ms — время загрузки рынков и котировок, НЕ чистая сетевая задержка.
Сравнения котировок не синхронизированы и не учитывают комиссии,
проскальзывание, глубину стакана, ограничения переводов и регионов.
Для круглосуточной работы нужен постоянно активный процесс; бесплатный
Render Web Service засыпает, поэтому он не подходит для надёжного 24/7.
